# 06 — UI Specification

Two surfaces: **Popup** (launcher) and **Manager** (full-tab SPA, 5 tabs).
Svelte 5 runes, scoped styles, CSS custom properties for theming. No CSS
framework.

## 3. Manager layout

```

├────────────────────────────────────────────────────────────┤

```

Max content width 960px, centered. Settings/About open as tabs too (footer
links = same routes). `<LegalGate>` renders as a full overlay when required.

### 3.1 #import

1. **Idle:** `<DropZone>` (dashed border, accent on dragover) — "Drop a
   bookmark file or *browse* — .html, .json, .csv · max 25 MB".
2. **Parsed:** two-column: left `<TreePreview>` (read-only tree, badges
   `new`/`dup`); right `<StatsCard>` (bookmarks / folders / depth /
   duplicates) + `<WarningList>` (collapsible) + `<ImportOptions>`:
   - Merge mode radio (New folder ▸ default · Merge · Replace all).
     Replace shows a danger callout: "Deletes ALL current bookmarks. A JSON
     safety backup will download first."
   - `[x] Skip duplicates already in this browser (n found)` — **disabled and
     unchecked when Replace is selected**, with the note "Existing bookmarks
     are being replaced". Skipping against a tree that is about to be deleted
     would silently drop everything (`03 §1`, `05 §3`).
   - Primary button `Import n bookmarks`, where n is `stats.bookmarkCount`
     (bookmarks only). The progress bar uses `stats.toCreate` (folders
     included) — two different numbers by design (`02 §4`).
3. **Writing:** `<ProgressBar>` (determinate) + current path line +
   `Cancel` + "Keep this tab open" notice.
4. **Done:** `<ResultCard>` (created / skipped / warnings) + `[Open Edit tab]`
   `[Import another file]`. Cancelled/error variants include copyable detail.

### 3.2 #export

Left: `<FolderPickTree>` with tri-state checkboxes under "Everything" master
toggle. Right: `<FormatSelect>` (radio cards HTML · JSON · CSV · Markdown,
one-line description each + per-format note, e.g. CSV: "empty folders not
preserved"), format options (CSV delimiter, MD style), then
`Export n bookmarks ⬇`. Success toast with filename.

### 3.3 #edit

Toolbar: `<SearchInput>` (⌘/Ctrl-F focuses) · `New folder` ·
`Find duplicates` · `Expand all / Collapse all`.
Body: `<TreeView>` (editable) — rows: disclosure ▸, favicon placeholder
(folder/link glyph — no remote favicons), title, muted domain, hover-actions
(rename ✎, delete 🗑, ⋯ menu: Move to…, Copy URL, Open).
Interactions: drag & drop with drop-line indicator (HTML5 DnD wrapped in a
Svelte action `draggableNode`); F2 rename; Del delete (confirm shows
descendant count for folders); Enter opens bookmark; full arrow-key tree
navigation (see §5). `<DuplicatePanel>` slides in from right: groups by URL,
per-item delete + "Keep first in each group" bulk (confirm dialog).
Empty state: friendly illustration + "Import some bookmarks →".

### 3.4 #settings

Single column of `<SettingRow>`s: Language (EN/VI/JA select) · Theme
(System/Light/Dark segmented) · Default export format · Default import mode ·
CSV delimiter. Auto-save + saved toast. Footer: "Reset to defaults".

### 3.5 #about

`<AboutCard>`: logo, name, version (from manifest at runtime), tagline;
links: **GitHub repo ↗** · Report an issue ↗ · Changelog ↗;
**Third-party dependencies: None 🎉** (statement, satisfies the requirement);
Donate: GitHub Sponsors (`poli0981`) ↗ · Ko-fi (`skullmute`) ↗ — full handle
list in `14 §5`, sourced from `.github/FUNDING.yml`;
Legal block: EULA · License (GPL-3.0) · Disclaimer · Privacy Policy — each →
GitHub `legal/` file; "Legal terms accepted on <date> · version n".

## 4. Component inventory (`src/lib/components/`)

`TabBar` · `LanguageSwitcher` · `ThemeToggle` · `DropZone` · `TreePreview` ·
`TreeView` · `TreeNode` (recursive, `{#await}`-free, lazy children) ·
`FolderPickTree` · `StatsCard` · `WarningList` · `ImportOptions` ·
`FormatSelect` · `ProgressBar` · `ResultCard` · `SearchInput` ·
`DuplicatePanel` · `ConfirmDialog` (native `<dialog>`) · `Toast` (queue,
auto-dismiss 4s, ARIA `status`) · `SettingRow` · `AboutCard` · `LegalGate` ·
`Button` · `Callout`.

Rule: components ≤ 300 lines; recursive tree logic isolated in `TreeNode`.

## 5. Accessibility & keyboard

- Tree uses `role="tree"/"treeitem"`, `aria-expanded`, `aria-level`; arrow
  keys per WAI-ARIA tree pattern (↑↓ move, → expand/first child, ← collapse/
  parent, Home/End, type-ahead by first letter).
- All actions reachable without a mouse; DnD has menu-based "Move to…" parity.
- Dialogs: native `<dialog>` + focus trap + `Esc`.
- Progress announced via `aria-live="polite"` every 10%.
- Contrast ≥ 4.5:1 in both themes (tokens chosen accordingly).

## 6. Iconography

Inline SVG only (16/20px, `currentColor`), stored as tiny Svelte components in
`components/icons/`. No icon-font, no external icon package.
